# ADR-0006 — Wrapper Electron: carregamento estático em produção + CSP rígida + preload isolado

- **Status**: Aceita
- **Data**: 21/09/2026
- **Decisores**: Time de desenvolvimento Mesa Justa (com apoio de IA generativa agêntica)
- **Áreas afetadas**: Desktop (Electron), Build (Next.js), Segurança (CSP)

---

## Contexto

O RNF-03 exige empacotamento desktop para Windows 10/11. O `electron-wrapper` precisa carregar a aplicação em dois modos: em desenvolvimento apontando para o servidor Next.js local (`http://localhost:3000`) e, em produção, sem depender de servidor remoto — `file://` com o build estático. Viabilizar `file://` exige `next.config.mjs` com `output: 'export'` condicional à flag `ELECTRON_BUILD`, além de uma CSP compatível com conteúdo estático e uma ponte mínima (`preload`) para funcionalidades nativas.

## Decisão

- **Janela segura**: `width: 1280, height: 800`, `nodeIntegration: false`, `contextIsolation: true`, `webSecurity: true`, `preload: electron/preload.js`.
- **Carregamento**: produção usa `loadFile(out/index.html)`; desenvolvimento usa `loadURL(http://localhost:3000)` (com DevTools abertos).
- **Modo de build**: `ELECTRON_BUILD=true npm run build` ativa `output: 'export'` no Next.js (pasta `out/`); `electron-builder` empacota `out/**` + `electron/**` para NSIS Windows.
- **CSP em produção** via `session.defaultSession.webRequest.onHeadersReceived`: `script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self' https://api.mesajusta.com.br` (em dev a CSP é ignorada para não quebrar HMR).
- **Ponte nativa mínima** via `contextBridge.exposeInMainWorld('electronAPI', { getVersion, openExternal })` — nada de IPC além do necessário no MVP.

## Alternativas consideradas

| Alternativa | Prós | Contras | Veredito |
|---|---|---|---|
| **`output: 'export'` + NSIS (escolhido)** | Instalador `.exe` leve e offline-safe; sem servidor embutido | Read API routes desativadas no bundle estático (MVP usa consultas já servidas em build/ambiente) | **Aceito** |
| Empacotar o Next.js servidor dentro do Electron | API local viva | Aumento de tamanho/complexidade; mantém servidor Node interno (superfície de ataque) | Rejeitado |
| Tauri (substituir Electron) | Menor footprint | Reescrita do wrapper; equipe já familiarizada com Electron | Rejeitado |

## Consequências

**Positivas**
- Instalador único `Mesa Justa Setup 1.0.0.exe` (~101 MB) validado em Windows 11 com atalho no menu Iniciar.
- CSP ativa sem violações no bundle estático; `nodeIntegration: false` + `contextIsolation: true` mitigam vetores de XSS/desktop.
- Ponte `preload` expõe superfície mínima ao renderer.

**Negativas / trade-offs assumidos**
- Bundle estático não executa Route Handlers — qualquer necessidade de API em runtime do desktop exige conectividade com o backend publicado (`connect-src https://api.mesajusta.com.br`).
- `unsafe-inline` para styles é necessário ao export estático do Next (trade-off aceito; scripts permanecem `'self'`).
- Sem multi-instância/cache offline avançado no MVP (roadmap V2).
